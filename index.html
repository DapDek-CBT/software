FAQ

Common questions

Do I need internet to use DapDek CBT?

Only to download and install it the first time. After that, it runs entirely on your school's own network — exams, grading, report cards, everything — with no internet connection needed.

How does the 7-day free trial work?

Install the Admin & Server app and you get full access to every feature for 7 days — no card details needed to start.

What happens after the trial ends?

Your installation shows a unique Product Key. Send it to us and we'll send back an Activation Code to unlock it — tied to your school's own installation, so it can't be shared or reused elsewhere.

How many computers do I need, and how do they connect?

One computer (usually the school office) runs the Admin & Server app. Every Teacher, Student or Parent computer installs its own matching app and connects to that one computer over your school's network.

Can parents check results from outside the school network?

By default, the Parent app connects over your school's own network, the same way the Teacher and Student apps do — so it needs to be used on that network. It's not designed for access from an entirely separate internet connection, such as a parent's home Wi-Fi.

Is our school's data backed up?

Yes — the Admin & Server app automatically keeps a daily local snapshot, with the last 60 days always kept.
